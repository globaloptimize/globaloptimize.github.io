# Portrait Setup

The homepage directly loads:

```html
<img src="ming_shi_69.jpg" alt="Portrait of Ming Shi">
```

Place `ming_shi_69.jpg` in the same folder as `index.html`:

```text
website-root/
├── index.html
├── ming_shi_69.jpg
├── research.html
├── publications.html
├── studentsandteaching.html
├── service.html
└── assets/
```

The clock is displayed below the portrait card and no longer overlaps the photograph. The photo card is wider on desktop and remains responsive on tablets and phones.

For performance, compress the JPEG but keep the filename unchanged. A width of approximately 900–1200 pixels and a file size below about 500 KB are appropriate for this layout.
